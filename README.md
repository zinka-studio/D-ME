# D-ME

אוטומציה לאינסטגרם שרצה על Cloudflare, בלי שרת משלך ובלי תשלום להתחלה.

מישהו מגיב על פוסט או ריל שלך, או עונה על סטורי, עם מילת מפתח שהגדרת. D-ME שולחת לו הודעה פרטית עם הלינק. אפשר להגדיר שהלינק יישלח רק לעוקבים: מי שלא עוקב מקבל בקשה לעקוב וכפתור בדיקה, והלינק נשלח רק אחרי שהאינסטגרם מאשרת שהוא עוקב.

לכל התקנה יש דשבורד בעברית באינטרנט: יוצרים אוטומציות, בוחרים פוסט, ריל או סטורי, רואים כמה הגיבו וכמה הודעות נשלחו.

## איך מתקינים: עם סוכן AI

אין צורך להבין בקוד. פותחים את התיקייה הזאת ב-**Claude Code** או ב-**Codex**, ואם אפשר מחברים גם את **Claude בכרום**, וכותבים לסוכן:

```text
קרא את AGENTS.md והדרך אותי צעד אחר צעד להתקנה של D-ME, מהרגע שאין לי שום חשבון ועד שהדשבורד רץ.
```

הסוכן מוביל אותך בעברית: פתיחת חשבון Cloudflare חינמי, חשבון מפתחים ואפליקציה ב-Meta, ההתקנה עצמה, חיבור האינסטגרם, ובדיקה אמיתית בסוף. סיסמאות וטוקנים לא עוברים דרכו: אתה מקליד אותם בעצמך בטרמינל או באתר.

אפשר גם לעבור על השלבים לבד, בעמוד מדריך אינטראקטיבי עם כפתורי העתקה ורשימת התקדמות: פותחים את [docs/guide.html](docs/guide.html) בדפדפן.

## מה צריך לפני שמתחילים

- חשבון אינסטגרם **מקצועי** (עסקי או יוצר).
- חשבון פייסבוק, לצורך חשבון מפתחים ב-Meta.
- מחשב עם Node.js 20 ומעלה. אם אין, הסוכן ינחה איך מתקינים.
- אימייל, ומספר טלפון לאימותים.

## מה בפנים

| תיקייה | תפקיד |
|---|---|
| `src/` | קוד ה-Worker: webhook, לוגיקה, ה-API של Meta, הדשבורד |
| `migrations/` | מבנה מסד הנתונים (D1) |
| `scripts/setup.mjs` | סקריפט ההתקנה: מסד, secrets, פריסה |
| `AGENTS.md` | ההנחיות לסוכן |
| `docs/AGENT_PLAYBOOK_HE.md` | המדריך המלא שהסוכן עוקב אחריו |
| `test/` | בדיקות אוטומטיות |

## התקנה ידנית, בקצרה

```bash
npm install
npx wrangler login
npm run setup -- --apply
```

ההתקנה צריכה לרוץ בטרמינל שלך, כי היא שואלת בהזנה מוסתרת את טוקן האינסטגרם ואת ה-app secret. בסוף מתקבלת כתובת הדשבורד וכתובת ה-webhook שמחברים ב-Meta. את כל הפרטים, כולל חיבור ה-webhook, מצאו ב-[docs/AGENT_PLAYBOOK_HE.md](docs/AGENT_PLAYBOOK_HE.md).

## פיתוח מקומי

```bash
npm install
cp .dev.vars.example .dev.vars   # ממלאים ערכי בדיקה
npx wrangler d1 migrations apply d-me-db --local
npm run dev                      # http://localhost:8787/admin
npm test
```

## אבטחה

- חתימת ה-webhook של Meta נבדקת על גוף הבקשה הגולמי, בהשוואה בזמן קבוע.
- הטוקנים, ה-app secret וסיסמת הניהול נשמרים כ-secrets ב-Cloudflare בלבד.
- ה-API של הניהול דורש סיסמה ולא מחזיר סודות. שאילתות ה-D1 מוכנות מראש.
- הדשבורד מוגש עם כותרות אבטחה קשיחות (CSP, ללא framing).
