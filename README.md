# D-ME

אוטומציה לאינסטגרם, מותקנת בעזרת Claude, בלי קוד ובלי אפליקציית Meta.

- **תגובה שמביאה לינק:** מישהו מגיב על פוסט או ריל שלך (או עונה על סטורי) במילה שבחרת, או בכל תגובה. הוא מקבל תגובה פומבית והודעה פרטית עם לינק.
- **רק לעוקבים:** אפשר להגביל את הלינק לעוקבים בלבד. מי שלא עוקב מקבל בקשה לעקוב וכפתור "עקבתי".
- **תזמון פוסטים:** מעלים תמונה, סרטון או קרוסלה, מתזמנים, והאוטומציה נדלקת לבד ברגע שהפוסט עולה.
- **דשבורד בעברית:** יצירת אוטומציה, יצירת פוסט, פרסומים מתוזמנים, אנליטיקות, וחיבורים ושימוש. בדסקטופ ובמובייל.

## איך מתקינים

מעתיקים את ההודעה מ-[START_HERE.md](START_HERE.md) ומדביקים אותה בשיחה חדשה עם Claude. Claude מוביל שלב אחרי שלב ומחכה לאישור בכל שלב. מעדיפים לבד? [docs/guide.html](docs/guide.html).

מה צריך:
- חשבון אינסטגרם מקצועי (עסקי או יוצר) וציבורי.
- אימייל.

במהלך ההקמה פותחים חשבון ב-Zernio וחשבון חינמי ב-Cloudflare.

## איך זה בנוי

| חלק | תפקיד |
|---|---|
| [Zernio](https://zernio.com) | המנוע: החיבור לאינסטגרם, האזנה לתגובות, שליחת הודעות ופרסום פוסטים |
| הדשבורד (הריפו הזה) | ממשק בעברית ב-Cloudflare Workers, מעל ה-API של Zernio. בלי מסד נתונים |
| Claude | מקים את הכול, ומבצע בקשות בשפה רגילה דרך המחבר של Zernio |

כל החלקים עובדים על אותם נתונים. מה שנעשה בדשבורד נראה ל-Claude, ולהפך.

## עלויות

- **Cloudflare Workers:** החבילה החינמית מספיקה לדשבורד.
- **Zernio:** לפי התוכנית שלהם. המחיר המעודכן נמצא באתר שלהם.
- **הקוד:** חינמי, ברישיון MIT.

## מה בפנים

| נתיב | תפקיד |
|---|---|
| `src/` | הדשבורד וה-API שלו (`zernio.ts`, `admin-ui.ts`, `index.ts`) |
| `public/` | הפונט Rubik והאייקונים (נארזים לתוך הקוד בפריסה) |

| `test/` | בדיקות (`npm test`) |

## פיתוח

```bash
npm ci
npm test
npx wrangler deploy
```

סודות ב-Worker: `ADMIN_TOKEN` (סיסמת הדשבורד) ו-`ZERNIO_API_KEY`. לפיתוח מקומי מעתיקים את `.dev.vars.example` ל-`.dev.vars`.
