הדרך הקלה: Claude מוביל

מעתיקים את ההודעה ומדביקים אותה בשיחה חדשה עם Claude (claude.ai, האפליקציה, Claude Code או Codex):

אני רוצה להקים את D-ME: אוטומציה לאינסטגרם. מי שמגיב על פוסט או ריל שלי במילה שבחרתי מקבל הודעה פרטית עם לינק, אפשר גם רק אם הוא עוקב. אפשר גם לתזמן פוסטים חדשים עם אוטומציה שנדלקת כשהם עולים. Zernio מריצה את הכול, ויש דשבורד בעברית על Cloudflare.

המשימה שלך: להקים לי את זה מאפס ולהוביל אותי בעברית פשוטה, שלב אחרי שלב.

1. הורד את הריפו https://github.com/zinka-studio/D-ME (git clone, ואם אין git, את קובץ ה-ZIP) ותיכנס לתיקייה.
2. קרא את AGENTS.md ואת docs/AGENT_PLAYBOOK_HE.md, ופעל לפיהם לכל אורך העבודה.
3. תתחיל משלב 0. אין לי עדיין אף חשבון: לא Zernio ולא Cloudflare.

כללים:
- שלב אחד בכל פעם. תסביר מה עושים, תחכה שאכתוב שסיימתי, תבדוק, ורק אז תמשיך.
- סיסמאות של חשבונות אני מקליד רק באתרים עצמם, לא בצ'אט.
- לפני פרסום, תזמון, יצירה או הפעלה של אוטומציה, או פריסה, תציג לי את הפרטים המדויקים ותחכה ל"כן".
- אם משהו נכשל, תסביר בשפה פשוטה מה קרה ומה עושים.

השלבים שלמטה הם אותם שלבים, כדי לראות מה הולך לקרות או ללכת לבד.

חיבור Zernio ל-Claude

ככה Claude יכול לבדוק את החשבון, ליצור אוטומציות ולתזמן פוסטים. התחברות בדפדפן, בלי מפתח.

טוקן Cloudflare לפריסה

אצלך, Claude פותח טופס
  1. נכנסים ל-dash.cloudflare.com/profile/api-tokens, ואז Create Token.
  2. ליד Edit Cloudflare Workers, לוחצים Use template.
  3. ב-Account policy בוחרים את החשבון שלך. ב-Token expiration בוחרים 30 days.
  4. Continue to summary, ואז Create Token, ומעתיקים את הטוקן (מוצג פעם אחת).
  5. מדביקים אותו בטופס המאובטח ש-Claude פותח, ולא בצ'אט. ב-Claude Code מקומי מספיק npx wrangler login.
צילום מסך: יצירת הטוקן מהתבנית

איך יודעים שהצליח: Claude כותב שהטוקן תקין ומציג את שם החשבון.
